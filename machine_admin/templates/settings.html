Consultar pela API

O token sugerido no painel é somente leitura: jobs:read,results:read,exports:read. Use o número de uma consulta que sua integração pode acessar.

GET /api/v1/jobs/123/results?after_id=0&limit=100
Authorization: Bearer SEU_TOKEN

O retorno contém items e next_cursor. Informe esse cursor como after_id para carregar a próxima página; quando ele for nulo, a leitura terminou.

Para gerar um arquivo, conceda explicitamente exports:write e envie {"format":"xlsx"} a POST /api/v1/jobs/123/exports. Consulte GET /api/v1/exports/{id} até o estado ready; o campo download_url fornece a rota para baixar com o mesmo Bearer autorizado.

Agendas usam GET /api/v1/schedules (schedules:read) e POST /api/v1/schedules (schedules:write). Campos, exemplos e respostas estão na documentação interativa.
